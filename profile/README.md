## About Gan Jiang

**Gan Jiang** is an intelligent scientific agent designed for **X-ray diffraction (XRD) analysis and materials structure discovery**.

It integrates specialized AI models, crystallographic databases, and professional analysis tools to support real-world XRD workflows—from diffraction data processing and phase identification to structural refinement and evidence-based interpretation.

## Core Capabilities

- **Diffraction data processing and format conversion**
- **Automated peak detection and phase identification**
- **Single-phase and multiphase analysis**
- **Crystal structure refinement**
- **Evidence-based result interpretation**
- **Intelligent orchestration of professional XRD tools**

## Open-Source Policy

Gan Jiang is a **commercial scientific platform**. Its core system and proprietary technologies are not fully open-sourced.

This organization provides selected open-source components, research tools, technical resources, and ecosystem projects for academic research and community collaboration.
